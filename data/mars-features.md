# Mars feature catalogue and contours

The offline bundle `js/marsdata.js` is generated by `tools/mars-features.py`.
All geometry is geographic (east longitude, planetocentric latitude), not
screen-space ellipses. Rendering, sunlight, limb clipping and picking use the
same oblate globe and orientation as the telescope's Mars texture. Features
remain exclusive to **Moons of Mars**; searches open that view.

## Inputs inspected on 2026-11-11

1. **IAU/USGS Gazetteer** — approved names, IDs, centers, types and extents:
   https://planetarynames.wr.usgs.gov/Page/MARS/target
   https://asc-planetarynames-data.s3.us-west-2.amazonaws.com/MARS_nomenclature_center_pts.kmz
   2,055 records, 2,054 unique IDs (Bohar/16054 occurs twice identically).
   There are 1,242 unique named craters and 126 albedo features. The Gazetteer's
   diameter is an approximate diameter or longest dimension, not a second
   ellipse axis. SHA256:
   `7363b3323dc401876cfc25616555e44d65bf57881d0e6a503910c5cdc4af8613`.
2. **OpenPlanetaryMap's USGS nomenclature polygons** — older public bulk
   geometry, matched to current names by USGS feature ID:
   https://openplanetarymap.org/datasets/
   https://openplanetary.carto.com/u/opmbuilder/dataset/opm_499_mars_nomenclature_polygons
   Export via CARTO SQL: `SELECT link,name,code,diameter,ST_AsGeoJSON(the_geom)
   AS geometry FROM opm_499_mars_nomenclature_polygons`.
   The inspected export has 1,652 rows. Generated crater circles, old albedo
   rectangles, null geometries, bounding rectangles, and materially changed
   extents are excluded. Exterior components are retained separately; outline
   vertices are simplified to 0.025 degrees without collapsing closed rings.
   Source response SHA256:
   `4f85f6c7aa7dc08890fe736e3ecb07ed9cf3f32702c62b344063ded16e5408c2`.
3. **Robbins 2020 crater measurements** — public release linked by its author:
   https://craters.sjrdesign.net/
   https://craters.sjrdesign.net/Catalog_Mars_Release_2020_1kmPlus_FullMorphData.csv.zip
   Method: Robbins & Hynek (2012), doi:10.1029/2011JE003966.
   The downloaded release has 385,049 rows and includes ellipse centers, major
   and minor diameters, orientation, uncertainties, and traced rim fraction.
   The author documents historical orientation bugs. This importer uses the
   2020 release (angles in 0–180 degrees), interpreted counterclockwise from
   east in the local surface plane, following the published fitter convention.
   Fit quality gates: at least 75% rim coverage, orientation standard error
   <=15 degrees, ordered positive axes, and valid angle. Matching requires
   centers within max(2 km, 12% of named diameter) and circular diameters
   within 10%; candidates are scored by both errors and matched one-to-one.
   These gates reject ambiguous matches and poor fits; they do not constitute
   an independent scientific revalidation of every fitted orientation.
   ZIP SHA256:
   `a642daf677a936834424ec2ba16a70857e4a587b060168334ed2977cce496354`.
4. **Curated albedo identification contours** — `mars-albedo-contours.json`.
   Eight approximate envelopes digitised against Martin R. Lewis's
   *Mars 2022–23 Albedo Map*, dated 29 November 2023, referenced by the BAA:
   https://britastro.org/section_information_/mars-section-overview/maps-of-mars
   Raw pixel vertices and the source URL are retained for review. Source grid:
   Lambert cylindrical equal-area, south up, increasing west longitude,
   **planetographic** latitude. The importer converts to planetocentric
   latitude using Mars flattening 0.00589. The source image is not bundled.
   These envelopes are identification aids, not measured edges: connected
   markings have subjective divisions, and dust changes their appearance.
   The source epoch and approximation are explicitly shown in feature cards.

## Geometry choice

- Craters with accepted Robbins matches use measured ellipse centers, full
  axis lengths and position angles. Others use their official diameter as a
  circular approximation, explicitly identified as such.
- Compact mountains, volcanic domes/calderas and basins can use an **area-moment
  equivalent ellipse** fitted to the footprint in local azimuthal equidistant
  kilometres. It is accepted only for a single component, points within 2,000
  km of the center, and normalized radial RMS residual <=0.12. This is a
  derived approximation, not an independently measured ellipse.
- Valleys, canyon systems, irregular regions and rejected ellipse fits use
  mapped polygon footprints. The detail card distinguishes their provenance.
- Seven curated albedo envelopes are polygons; the compact Solis Lacus
  envelope uses a derived ellipse. Other albedo names remain center markers.
- The generated bundle currently contains 1,017 measured crater ellipses,
  65 footprint-derived ellipses, 533 mapped polygon features, eight curated
  albedo contours, and 431 extent-only/point features.

The first renderer checks include the nearly circular Gale ellipse
(154.599 x 153.373 km), the elongated Huygens ellipse (484.481 x 450.190 km,
angle 129.225 degrees), Olympus Mons's derived ellipse, Valles Marineris's
irregular footprint, and the separate albedo/topographic Syrtis Major names.
Names are escaped as external catalogue data. Geometry stays lazy until a
selected feature or nearby pick requires it. Labels use apparent-size
thresholds and a maximum of 28 candidates to keep a full planet readable.

## Rebuilding

Download the three inputs to temporary storage, export the CARTO JSON above,
then run (Python standard library only):

```sh
python3 tools/mars-features.py /path/MARS_nomenclature_center_pts.kmz /path/mars-polygons.json /path/Catalog_Mars_Release_2020_1kmPlus_FullMorphData.csv.zip
node tests/marsfeatures.mjs
```

`--output /path/marsdata.js` allows a deterministic comparison build.
`--albedo /path/contours.json` selects another curated contour file.
Browser interaction/visual checks: `node tests/marsfeatures-browser.mjs`
(with `PLAYWRIGHT` and `CHROME` as documented in the browser harness).
